Como jogar

  • O mapa começa com a palavra do tema aberta e as vizinhas dela como casinhas vazias, uma para cada letra.
  • Cada fio liga duas palavras que têm alguma relação: “bola” e “gol”, “rei” e “coroa”. Às vezes a ligação é um trocadilho, como “banco” de reservas e “banco” de dinheiro.
  • Digite qualquer palavra que você acha que está no mapa. Se acertar, ela aparece sozinha. Acentos e maiúsculas não importam.
  • Cada palavra que você descobre faz brotar as vizinhas dela no anel seguinte. As palavras mais distantes só aparecem quando você abre o caminho até elas.
  • Toque numa palavra para destacar os fios dela.
  • Travou? Toque em Dica e escolha uma palavra escondida: aparece uma pista sobre ela, como “propriedade de todos os seres vivos” para vida. A pista fica guardada na palavra.
  • Arraste as palavras para onde quiser: os fios puxam as vizinhas e as outras abrem espaço. Arraste um fio para levar as duas pontas juntas. Use dois dedos ou a roda do mouse para dar zoom.
  • Sacudir organiza o mapa: desembaraça os fios, aproxima as palavras ligadas entre si e deixa as ligações fáceis de enxergar.

Quanto mais rápido e com menos dicas, mais pontos.

Desistir?

Todas as palavras serão mostradas e esta partida não vai pontuar. Dá para jogar de novo depois.
