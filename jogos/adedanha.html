O clássico STOP: sorteia uma letra e todo mundo corre para preencher as categorias. Quem completar primeiro grita STOP! Cada um joga no próprio celular ou computador.

Criar uma sala

Você vira o anfitrião: escolhe as categorias, as letras e o número de rodadas.

Entrar com código

Peça o código de 4 letras para quem criou a sala.

Como se joga

  1. Um jogador cria a sala e passa o código (ou o link) para os outros. A cada rodada, uma letra é sorteada para todos ao mesmo tempo.
  2. Preencha cada categoria com uma palavra que comece com a letra. Com tudo preenchido, aperte STOP!: os outros ganham 5 segundos para terminar.
  3. Na conferência, todos veem as respostas. Marque Não vale nas que estiverem erradas: com a maioria dos outros jogadores, a resposta é anulada.
  4. 10 pontos por resposta que só você deu, 5 por resposta repetida e 0 para em branco, letra errada ou anulada. Acentos e maiúsculas não contam na comparação.
